# 비전제일교회 청소년부 신앙 성장 웹앱 v6.5

> 압축을 풀면 맨 바깥의 `1_RUN_IN_SUPABASE.sql`을 Supabase SQL Editor에서 먼저 실행하세요. 새 테이블 생성과 스키마 캐시 갱신까지 한 번에 처리합니다.

## v6.5 조회수

- 관리자 대시보드에 홈페이지 전체 조회수와 한국시간 기준 오늘 조회수 표시
- 게시판 목록과 게시글 상세 화면에 글별 조회수 표시
- 같은 브라우저 세션에서는 홈페이지 1회, 게시글별 1회만 집계하여 반복 새로고침 중복 방지
- 조회 집계는 서버 API와 보안 함수로 처리하여 서비스 역할 키가 브라우저에 노출되지 않음

이미 v6.4 신앙생활 SQL을 실행한 운영 DB라면 `supabase/migration_v6_5_views.sql`만 추가 실행해도 됩니다. 처음 적용하거나 실행 여부가 확실하지 않다면 압축파일 맨 바깥의 통합 SQL을 실행하세요.

## v6.4 신앙생활 체크 · 성경 66권 진도

- 관리자와 교사가 학생별·날짜별로 `성경읽기 / 기도 / 큐티 / 예배 참석`을 체크
- 학생은 자신의 신앙생활 기록만 읽을 수 있고 다른 학생의 기록은 조회할 수 없음
- 구약 39권·신약 27권, 성경 전체 1,189장을 책별·장별로 체크
- 장별 체크 시 선택한 날짜의 `성경읽기` 항목도 자동 완료
- 기간을 선택해 학생별 실천 횟수·실천률·성경 장별 진도를 한눈에 확인
- 휴대폰에서는 체크 카드와 장 번호가 터치하기 편한 형태로 자동 전환

### v6.3에서 업데이트하는 순서

1. Supabase → SQL Editor에서 `supabase/migration_v6_4_faith.sql`을 한 번 실행합니다.
2. 이 ZIP의 파일을 기존 GitHub 저장소에 덮어쓰고 Commit합니다.
3. Vercel 자동 배포 후 관리자·교사·학생 계정으로 각각 `신앙 체크 / 나의 신앙` 메뉴를 확인합니다.

새 Supabase 프로젝트라면 `supabase/schema.sql` 하나에 v6.4 구조까지 모두 포함되어 있습니다.

## v2 이전 버전에서 Supabase와 Vercel을 사용 중인 경우

### 1. Supabase에 DB 업데이트
Supabase → SQL Editor → `supabase/migration_v2.sql` 내용을 전부 붙여넣고 Run.

`Success. No rows returned`가 나오면 정상입니다.

### 2. GitHub 파일 업데이트
이 ZIP의 프로젝트 파일을 기존 GitHub `youth-growth-server` 저장소에 덮어씁니다.
`.env.local`은 절대 GitHub에 올리지 마세요.

특히 새 파일:
- `app/api/admin/student/route.ts`
- `supabase/migration_v2.sql`

수정 파일:
- `app/page.tsx`
- `app/globals.css`
- `package.json`
- `supabase/schema.sql`

GitHub에서 Commit changes 하면 Vercel이 자동으로 새 배포합니다.

## 중요
`package.json`의 TypeScript는 `5.9.3`으로 고정했습니다. 이전 Vercel 빌드에서 TypeScript 7 계열로 인한 오류를 피하기 위한 설정입니다.

- 선생님: 신앙생활 기록·전체 조회, 점수, 메달, 게시판, 순위
- 학생: 자신의 신앙생활·성경 진도 조회, 나의 성장, 메달, 게시판, 순위


## v3 추가 기능
- 관리자와 교사 모두 `학생 관리` 메뉴 진입 가능
- 학생 관리 화면을 `학생 목록 / 교사 목록` 탭으로 분리
- 교사 계정은 학생/교사 목록 조회만 가능
- 관리자는 학생 등록/수정, 교사 추가/수정/삭제 가능
- 교사 계정 수정/삭제 API 추가
- v2 마이그레이션을 이미 실행했다면 v3는 추가 SQL 불필요


## v4 메달 조건
- 관리자 → 학생 관리 → 정보 수정에서 메달 미션 체크 가능
- 동메달: 40점 이상 + 봉사
- 은메달: 동메달 조건 + 80점 이상 + 제자훈련 + 신약통독
- 금메달: 은메달 조건 + 전도 + 구약통독
- 메달 화면에 학생별 점수/미션 완료 상태 표시
- 기존 DB 필드(service, nt_read, discipleship, ot_read, evangelism)를 사용하므로 추가 SQL은 필요하지 않습니다.


## v5 학생 메달 비교
- 학생 계정도 전체 학생의 메달 현황 확인 가능
- 점수, 현재 메달, 봉사/제자훈련/신약통독/전도/구약통독 상태 비교
- 자기 행은 강조 표시
- 메달 진행 기준으로 정렬
- 다른 학생의 상세 점수 사유/활동 내역은 비공개 유지
- 추가 SQL 필요 없음


## v6 점수 내역
- 관리자/교사 메뉴에 `점수 내역` 추가
- 관리자는 모든 학생 점수 기록 확인 가능
- 교사도 모든 학생 점수 기록 확인 가능
- 학생은 `나의 점수`에서 자신의 기록만 확인
- 날짜, 학생, 점수 아이콘/점수, 분류, 사유, 지급자 표시
- 학생/분류/검색 필터 제공
- 기존 activities 데이터를 그대로 사용하므로 추가 SQL 필요 없음


## v6.1 빌드 수정
- 점수 내역 검색에서 존재하지 않는 학생을 안전하게 처리

- Supabase 추가 SQL 필요 없음
- Vercel Production 환경변수 4개는 계속 필요:

  - NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
  - SUPABASE_SERVICE_ROLE_KEY
  - ADMIN_SETUP_SECRET
